nina1pp

Turn long YouTube videos into short vertical clips for TikTok.

What it does

nina1pp helps creators repurpose long-form video content. The user pastes a YouTube URL and selects a clip range; the tool downloads the source, cuts the segment, reformats it to a 9:16 vertical aspect ratio, and uploads the resulting clip to the user's own TikTok account as a draft for the user to review and publish.

How TikTok integration works

  • The user logs in with TikTok using TikTok's official Login Kit (OAuth 2.0).
  • nina1pp requests the user.info.basic scope to identify the authenticated user.
  • nina1pp requests the video.upload scope to send the prepared clip as a draft to the user's TikTok inbox.
  • The user reviews and publishes the draft from the TikTok mobile app. nina1pp never publishes content automatically without explicit user action.
